# my-dawn

새벽에 틀어두는 100개 장면입니다. 브라우저가 1920×1080 Canvas에 장면을 그립니다. 장면을 고른 뒤 **재생 길이 (초)**를 입력하면 그 시점에 멈춥니다. 칸이 비어 있으면 계속 반복됩니다. 파일에서 로컬 저장소를 지원하는 브라우저에서는 같은 위치에서 미리보기를 업데이트해도 장면별 재생 길이가 남습니다. 시간 설정 파일에서 장면의 기본 재생 길이를 바꾸면 새 기본값이 적용됩니다.

| 분류 | 장면 |
| --- | --- |
| 기존 10편 | 01–10 |
| 실내 | 11–25 |
| 물가 | 26–40 |
| 숲과 정원 | 41–55 |
| 밤하늘 | 56–70 |
| 도시와 교통 | 71–85 |
| 날씨와 전원 | 86–100 |

## 길이와 장면 편집

`timeline.json`에 장면별 설정이 있습니다.

| 설정 | 의미 |
| --- | --- |
| `durationSeconds` | 총 재생 시간. 예를 들어 `3600`이면 한 시간, `null`이면 계속 반복합니다. |
| `cycleSeconds` | 비나 물결 같은 화면 속 움직임이 한 바퀴 도는 시간입니다. |

기존 장면은 `sources/`에, 새 장면은 분류별로 `families/`에 있습니다. 장면 함수는 반복 주기의 진행도인 `phase`를 받아 한 프레임을 그립니다. 환경음은 `assets/audio/`의 WAV 음원을 반복하고 `assets/stills/`의 JPEG는 목록에서 사용합니다.

압축을 푼 폴더에서 다음 명령으로 미리보기를 만들 수 있습니다.

```sh
python3 build_preview.py
```

생성된 `my-dawn-preview.html`을 브라우저에서 열면 됩니다. 환경음을 바꾸려면 `ambience.py`를 편집하고 NumPy가 설치된 Python에서 `python3 build_audio.py`로 음원을 다시 생성한 뒤 미리보기를 다시 만들면 됩니다.
